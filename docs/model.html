使っているモデル

モデルNVIDIA Parakeet 日本語版（parakeet-tdt_ctc-0.6b-ja）の、sherpa-onnx による int8 ONNX 変換版
ライセンスCC-BY-4.0（NVIDIA）
ファイルmodel.int8.onnx（約 655 MB）、tokens.txt
置き場所%LOCALAPPDATA%\azarasi-voice\model
配布元このリポジトリの Release model-parakeet-ja-int8-v1

GPU ではなく CPU で動かすため、日本語専用の比較的小さなモデル（約 6 億パラメータ）を int8 に軽量化したものを使っている。

ダウンロード（model.rs、setup.rs）

  • ファイルごとの大きさと SHA-256 を src/model.rs に固定している。配布元のファイルが差し替えられても、知らないうちにモデルが変わることはない
  • ダウンロードには Windows 10 以降に標準で入っている curl.exe を使う。通信・TLS のライブラリを exe に入れずに済む
  • *.part に保存し、SHA-256 が一致したら正式な名前に変える。途中で失敗したファイルを「揃っている」と誤判定しない
  • 進み具合は、curl が書き込んでいるファイルの大きさから計算する
  • 失敗したら理由を表示し、「再試行」できる

なぜ GitHub Release に置くか

  • git には 100MB を超えるファイルを入れられない。Release のファイルは 1 つ 2GB まで置ける
  • 取得先がこのリポジトリの中で完結し、元の配布元（sherpa-onnx）の都合で消えたり変わったりしない

起動時の確認

  1. 起動時はファイルの大きさだけを見て、揃っているかを判断する。無ければセットアップ画面を出して、終わるまで待つ
  2. トレイに常駐した後、Windows のバックグラウンド モード（CPU と I/O の優先度が下がる）にしたスレッドで SHA-256 を確認する。確認中も音声入力は使える
  3. 壊れていたら、モデルをメモリから外し、壊れたファイルを消して、セットアップ画面を出す

起動のたびに 655 MB を読むが、SHA-256 の専用命令を持つ CPU なら 1 秒前後で済む。読んだモデルは Windows のファイルキャッシュに残るので、最初の音声入力のときのモデル読み込みも速くなる。

環境変数 AZARASI_VOICE_MODEL_DIR でモデルの置き場所を差し替えられる（動作確認用）。

メモリからの解放

  • モデルはホットキーを押した瞬間に読み込み始める。読み込み（約 1.2 秒）は話している間に終わる
  • 最後に使ってから設定した時間（既定 5 分）が経つと、メモリから外す。選択肢はフィボナッチ数列（1, 2, 3, 5, 8, 13, 21, 34, 55 分）と「解放しない」
状態メモリ
モデル読み込み中約 700〜800 MB
モデル解放後約 20 MB

スレッド数

論理コア数の 1/4 を、1〜4 に収める。ゲームなどの CPU を奪いにくいよう控えめにし、4 より増やしても速くならないので上限を 4 にしている。
