流れ

  1. Win + 左 Ctrl を押す
    • 音声認識スレッドにモデルの準備を頼む。メモリに無ければ読み込み始める（約 1.2 秒。話している間に終わる）
    • トレイのアイコンを赤くし、開始の効果音を鳴らす
    • 既定のマイクを開いて録音を始める。待機中はマイクを閉じている
  2. どちらかのキーを離す
    • アイコンを紺に戻し、終了の効果音を鳴らし、マイクを閉じる
    • 0.3 秒未満の録音は押し間違いとみなして捨てる
    • 音声をモノラル 16kHz に変換して、音声認識スレッドに渡す
  3. 音声認識
    • Parakeet 日本語版（int8 ONNX）を sherpa-onnx で CPU 実行する。13 秒の音声で約 0.3 秒
  4. 貼り付け
    • クリップボード経由で、開いているウィンドウに貼り付ける

ホットキー（hotkey.rs）

  • 低レベルキーボードフック（WH_KEYBOARD_LL）で、左 Win と左 Ctrl の状態を追う。両方が押された瞬間に開始、どちらかが離された瞬間に終了
  • Win を単独で離すとスタートメニューが開くので、ホットキーとして使った Win を離す直前に、割り当ての無い仮想キー（0xE8）を送って抑える
  • 自分で送ったキー入力（LLKHF_INJECTED）は無視する

録音（audio.rs）

  • 録音中だけマイクを開く。待機中はマイクを使わないので、Windows の「マイク使用中」の表示も出ない
  • マイクの形式（48kHz・ステレオなど）のまま受け取り、録音の終わりにモノラル 16kHz に変換する
  • 開始直後に WASAPI が「データの途切れ」を報告してくるが、録音には影響しないので無視する

貼り付け（paste.rs）

  1. Win / Ctrl が離されるのを待つ。押されたまま Ctrl+V を送ると、別のショートカット（Win + Ctrl + V など）になってしまう
  2. クリップボードの中身（文字か画像）を退避し、認識した文字を入れて Ctrl+V を送る
  3. 貼り付け先がクリップボードを読み終わるよう 0.3 秒待ってから、退避した中身を戻す

管理者権限で動いているウィンドウには、Windows の仕組み上、通常の権限のアプリからキー入力を送れないので、貼り付けられない。

効果音（sound.rs）

  • 音声ファイルは持たず、2 音の短い WAV をメモリ上で作って PlaySound で非同期に鳴らす。開始は低→高、終了は高→低
  • 設定画面でオフにできる

機器を起こす前置き

ワイヤレスヘッドセットなどは、無音が続くと省電力のために音声を止め、音が来てから再開する。再開までの間に鳴らした音は聞こえず、0.1 秒ほどの効果音は丸ごと消えてしまう。

  • しばらく鳴らしていなかったときは、聞こえない小さな低音（30Hz）を 0.4 秒流して機器を起こしてから鳴らす
  • 完全な無音だと「音が来ていない」とみなして起きない機器があるので、無音ではなく小さな音にしている
  • 0.25 秒では足りない機器があったため、余裕を見て 0.4 秒にしている
  • 最後に鳴らしてから 20 秒以内なら、機器はまだ起きているとみなして前置きを省く。終了の音と、続けて使ったときの開始の音は遅れない
