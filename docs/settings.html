設定ファイル（config.rs）

項目既定値内容
unload_after_minutes5最後に使ってからモデルをメモリから外すまでの分数。0 なら外さない
soundtrue録音の開始・終了で効果音を鳴らす
  • 置き場所は %APPDATA%\azarasi-voice\config.toml
  • 設定画面は別プロセスなので、本体とは設定ファイルを介してやりとりする。本体はホットキーを押したときに設定ファイルの更新時刻を見て、変わっていれば読み直す
  • 知らない項目があっても無視し、壊れていれば既定値を使う

自動起動（autostart.rs）

  • レジストリ HKCU\Software\Microsoft\Windows\CurrentVersion\Run の値 azarasi-voice に、exe のパスを登録する。オフにすると値ごと消す
  • オン・オフは設定ファイルに持たず、レジストリの値そのものを正とする。設定ファイルにも持たせると、タスクマネージャーなどで変えられたときにずれる
  • 登録するのは、今動いている exe と同じフォルダの azarasi-voice.exe。開発時の配置では古い exe の名前を変えるので、current_exe() をそのまま使うと消える予定のファイルを登録してしまう

タスクマネージャーの「スタートアップ アプリ」で無効にした場合、Windows は Run の値を残したまま別の場所に「無効」の印を付ける。設定画面は Run の値だけを見るので、チェックが入ったまま表示される。

Roaming と Local

もの置き場所理由
設定%APPDATA%（Roaming）小さく、どの PC でも同じでいてほしいもの
モデル%LOCALAPPDATA%（Local）大きく、作り直せるもの。Roaming は移動ユーザー プロファイルで同期される対象なので、大きいファイルは置かない
本体%LOCALAPPDATA%\Programsユーザーごとにインストールするアプリの慣例の場所。管理者権限が要らない

画面（settings.rs、setup.rs）

  • Slint のソフトウェアレンダラー（CPU 描画）だけを有効にしている。GPU を使わない
  • 別プロセスなので、閉じると画面の仕組みごとメモリから消える。本体に画面の仕組みを常駐させない
  • Slint は GPL-3.0 で利用している。「このアプリについて」タブに Slint の表示（AboutSlint）を置いている

タスクトレイ（tray.rs）

  • 待機中は紺、録音中は赤のアイコン
  • 左クリックで設定画面、右クリックでメニュー（設定を開く / 終了）

アイコン（icon_draw.rs）

  • 正面を向いた白いあざらしの顔を、画像ファイルを使わずに距離関数で描き、アンチエイリアスしている
  • トレイ・設定画面（実行時）と、exe のアイコン（build.rs から include!）で同じコードを使う
  • 小さいサイズでは細部が潰れるので、16〜24px では目と鼻だけ、32px ではひげを省く
